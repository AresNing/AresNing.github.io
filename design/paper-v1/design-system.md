# 素纸 · AresNing 博客设计系统

版本：v1 · 更新于 2026-09-13。状态：已完成主题与传播功能实现并发布，X 草稿卡片预览已验证。第 1–7 节保留初版视觉设计，第 8 节为初版验收历史；当前写作规范、深色规则和验收边界以文末“文章写作与传播规范”及最新验收记录为准；后续局部修订是否发布以对应记录为准。

## 1. 设计方向

像一本持续更新的编程笔记：暖白纸面、墨灰文字、克制的朱砂点色。纸张感主要来自底色、字形、版心与留白；颗粒只提供极轻的材质提示。

初版设计依据：改造前仓库使用 Hexo 5、NexT Gemini；当时站点名称为 `AresNing's blog`，描述为 `Hungry & Humble`，文章以中英文编程笔记为主。保留这些身份和内容，以横向导航和连续文章列表替代当前主题的左侧栏与分块阅读结构。

样式图：`style-board.png`，包含桌面首页、桌面文章页与移动端首页。它是 AI 生成的视觉概念稿；像素、文案及交互细节以本规范为准。文章名称取自真实内容，摘要为设计占位文案；文章示例中的引言和代码为排版示例，不表示改写原文。图中分页仅示意组件，不代表当前实际页数。

## 2. 色彩

| Token | 色值 | 用途 |
| --- | --- | --- |
| `--paper` | `#F7F5EF` | 页面主背景，暖白书纸 |
| `--ink` | `#292824` | 标题、正文、主要图标 |
| `--ink-muted` | `#68645E` | 分类、日期、辅助文字 |
| `--rule` | `#DCD7CD` | 装饰分隔线、代码块边线 |
| `--accent` | `#964D3B` | 链接、当前导航标记、焦点描边 |
| `--paper-inset` | `#EFEBE3` | 代码块、行内代码、轻微悬停背景 |
| `--selection` | `#E8D7C9` | 文字选中背景，搭配墨灰文字 |

朱砂色只点到为止，不给整块文章染色。正文链接带下划线；当前导航同时有文字或线条标识。浅色分隔线不用于唯一的控件边界，输入框用辅助文字色描边。

纯色背景对比度计算：正文 / 纸面约 13.53:1，辅助文字 / 纸面约 5.39:1，强调色 / 纸面约 5.63:1。正文、辅助文字和强调色均以普通文字至少 4.5:1 为设计门槛；最终纹理叠加后仍需复测。

## 3. 字体与排版

| 用途 | 字体栈 | 桌面字号 / 行高 | 手机字号 / 行高 |
| --- | --- | --- | --- |
| 首页站点标题 | Georgia、Songti SC、STSong、serif | 56 / 1.2 | 36 / 1.25 |
| 文章页标题 | 同上 | 40 / 1.3 | 30 / 1.35 |
| 列表文章标题、正文 H2 | 同上 | 28 / 1.45 | 24 / 1.45 |
| 正文 H3 | 系统无衬线 | 21 / 1.5 | 20 / 1.5 |
| 正文 | system-ui、PingFang SC、Microsoft YaHei、sans-serif | 17 / 1.9 | 16 / 1.85 |
| 导航与元信息 | 系统无衬线 | 14 / 1.6 | 13–14 / 1.6 |
| 代码 | ui-monospace、SFMono-Regular、Menlo、Consolas、monospace | 14 / 1.7 | 13 / 1.7 |

宋体用于标题，无衬线用于技术正文，等宽字体用于代码。优先使用系统字体；这些字体是按平台回退的选择，不要求全部安装，不依赖外部字体请求。中文标题不拉大字距；英文分类标签可用 0.06em 字距。正文左对齐，避免两端对齐造成空隙；长英文标题允许安全换行。

## 4. 布局与间距

- 间距尺度：4、8、12、16、24、32、48、64、96px。
- 全站页头最大宽度 1120px；首页文章区最大宽度 880px；文章正文最大宽度 720px。
- 桌面页面两侧留白至少 48px；手机左右各 24px，宽度低于 360px 时各 20px。
- 页头高约 80px，底部一条细线。首页标题区上下留白 80px / 64px，手机 48px / 40px。
- 首页每条文章上下留白 32px，手机 24px；条目之间只用细线分隔。分类到标题 12px，标题到摘要 12px，摘要到阅读链接 16px。
- 文章标题到正文 48px；正文段间 20–24px；H2 上方 48px、下方 20px。
- 宽度 ≥1200px：正文右侧可显示 160px 目录，间隔 48px；目录在滚动时保持可见。
- 768–1199px：单列正文，目录置于正文前并可折叠。
- 宽度 <768px：使用紧凑页头，搜索与菜单按钮保留；目录同样折叠，无固定侧栏。
- 表格和代码块在各自容器横向滚动，图片不超出版心，页面本身不能横向溢出。

## 5. 纸张材质

底色始终统一。若实现颗粒，使用可平铺的本地小纹理，亮度变化不超过约 1%，叠加不透明度建议 1–2%；缩小后几乎不可见，放大观察才有轻微细纤维感。

纹理层不接收指针事件，不参与辅助技术阅读；不使用持续动画或大幅实时滤镜。禁用纹理后，设计仍须成立。正文、图片、代码保持锐利，不给整页叠加模糊。

不使用泛黄旧报纸、折角、破边、污渍、大投影、纸张叠层或真实桌面背景。首页文章条目无卡片阴影；边角以直角为主，代码和输入框允许 2–4px 小圆角。

## 6. 页面与组件

| 组件 | 视觉与行为 |
| --- | --- |
| 页头 | 左侧 AresNing，右侧文章、归档、关于、搜索；分类与标签入口保留在文章区和归档页。当前导航用短朱砂下划线标记。 |
| 首页 | 保留原站名与 Hungry & Humble，下面直接进入文章列表。默认每条摘要最多两行，展示真实分类和已有日期；缺少日期时省略，不制造时间或阅读时长。 |
| 文章条目 | 分类、标题、摘要、阅读全文依次排列；标题和阅读链接指向同一篇文章。悬停时标题变强调色并出现细下划线，不位移。 |
| 分页 | 简单数字与前后页链接；当前页用强调色加下划线，同时设置当前页语义。单页内容不展示无用分页。 |
| 文章页 | 面包屑、标题、真实元信息、正文、上一篇/下一篇。桌面目录作为边栏；标题锚点滚动后不被页头遮挡。 |
| 引用 | 左侧 2px 强调色线，左内边距 20px；正文色不降低到难读的浅灰，背景保持纸色。 |
| 代码块 | 浅暖灰底、16–24px 内边距、小圆角。语言标签、复制按钮、横向滚动；复制后显示“已复制”，失败显示“复制失败”，不移动布局。 |
| 代码高亮 | 正文墨灰、注释辅助灰、关键字朱砂、字符串深绿 `#47604D`；避免多种鲜艳颜色。行号可选，不随代码一起复制。 |
| 表格 | 表头浅暖灰底，仅使用轻横线；数字按需右对齐。超宽表格局部滚动，保留清楚的列关系。 |
| 分类与标签 | 纯文字列表或文字加数量；标签不做彩色胶囊。分类筛选保留“全部”，空结果给出清除筛选入口。 |
| 搜索 | 点击搜索打开简洁面板，显示输入框和结果；空结果文案“没有找到相关文章”，保留清空入口。Esc 关闭并把焦点还给触发按钮。 |
| 归档 | 年份作为小标题，文章按时间纵向排列，日期与标题分列；移动端可将日期放到标题上方。 |
| 页脚 | 细线、作者、GitHub 和现有版权/主题署名要求，保持低调；不增加统计大卡片。 |

## 7. 状态与可访问性

- 控件具备默认、hover、focus-visible、active 和必要的 disabled 状态。键盘焦点用 2px 强调色描边，外偏移 3px。
- 小图标按钮的可点击区域至少 44×44px，提供中文可访问名称；搜索和移动菜单可用键盘操作，打开后管理焦点。
- 颜色过渡建议 140ms ease，不做页面入场动画；遵守 prefers-reduced-motion。
- 正文字号不随整体缩放降到难读的小字号；200% 缩放时信息和功能完整可用。
- 移动端打开菜单后可关闭、可导航；目录折叠按钮暴露展开状态。
- 无障碍和强制颜色模式下可移除纹理。首版聚焦浅色主题，深色主题另做配色验证。

## 8. 实现与验收记录

### 交互组件与 UI 一致性（2026-09-12 更新）

通用交互优先采用成熟组件或浏览器原生控件，业务代码只做内容适配。搜索与移动导航使用同一个 a11y-dialog 8.1.5 弹层组件；搜索匹配与相关性排序使用 Fuse.js 7.5.0；代码复制使用 ClipboardJS 2.0.11；目录折叠保留原生 details。来源、版本和维护约定见根目录 README。

搜索与导航共用暖白面板、细边线、遮罩、标题字号、关闭图标、圆角和内边距。所有操作按钮共用 `.ui-button`，图标热区为 44×44px，文字按钮至少 44px 高；输入框和相邻清空按钮等高。焦点使用统一 2px 朱砂描边、3px 外偏移；复制成功用深绿并显示“已复制”，失败用朱砂并显示“复制失败”。搜索摘要最多三行，避免移动端单条结果过高。

依赖精确锁版本，构建输出本地脚本及许可证，无运行时 CDN 请求。三个上游脚本合计 gzip 约 14KB（本地压缩计算，非线上传输测量），Fuse.js 在首次输入搜索时才加载。

本轮真实浏览器验证：桌面/移动弹层视觉；Tab 与 Shift+Tab 循环留在弹层内；Esc 和遮罩关闭后恢复触发按钮焦点；移动导航切换到桌面宽度后关闭并将焦点移至可见导航；英文错拼 `CompletableFutrue` 命中正确文章，中文“线程池”搜索正常；无结果、清空、重新打开保留查询正常；用本地临时服务器让 search.xml 首次返回 503，点击“重试”后成功恢复；ClipboardJS 复制成功且不带行号。1440、1024、768、390、320px 下弹层没有超出屏幕或引入页面横向溢出，控件点击高度均至少 44px，正常页面未发现控制台错误。

## 文章写作与传播规范（2026-09-13）

本节与 `scaffolds/post.md` 是后续文章的统一约定，主题模板负责落地样式。修改规则时同时更新模板与相关检查，不另建一套平行规范。

### 内容字段与发布状态

| 字段 | 规则 |
| --- | --- |
| `title` | 说明问题或主题，避免夸张承诺。推荐 12–32 个中文字符；英文技术名可适当放宽。改旧文标题不得改变已有链接。 |
| `description` | 人工写 40–100 字的一至两句话，交代主题、方法或读者收益；不要截取代码、目录或引语充当摘要。供列表、分享信息和封面复用。 |
| `intro` | 文章开头的导读，交代场景和范围；简短笔记可复用摘要，长文可增加适用条件。 |
| `kind` | `note` 表示学习笔记，`article` 表示已整理成完整叙述的文章。长度不代表质量；引用整理不得暗示原创发现或实验验证。 |
| `published` | 新文默认 `false`。正文、出处和必需字段完成后显式设为 `true`。空白与测试内容保留源文件，排除公开展示与搜索。 |
| `date` | 真实发布日期；历史时间不明就留空。不得用文件创建时间或本次样式修改日期补写历史发布日期。 |
| `updated` | 实际编辑更新日期，可包括标题、导读与配图整理。不是技术结论已复核的承诺；仅重新构建或切主题不更新。 |
| `permalink` | 已分享文章保持固定。精选文章必须显式锁定；本次三篇改题均保留原地址。 |
| `related` | 可选，人工指定最相关的文章路径（不含 index.html），优先于标签与分类匹配。精选文章应复核推荐关系。 |
| `featured` | 1–3，对应首页三个精选位。选择有清晰问题、完整摘要与实际内容的代表文章。 |
| `quote_attribution` | 学习整理或引用文章提供来源，例如“学习整理自作者《资料名》”；会随摘录图片导出。正文中的具体引用继续保留原作者。 |
| `diagram` / `diagram_alt` / `diagram_caption` | 配图地址、完整的文字替代、图示范围或来源说明。桌面 `.svg` 同时提供 `-mobile.svg`。 |

正文使用二级标题开始；旧文一级标题由主题降级，保持既有锚点。引用清楚区分原文、作者整理和个人判断。代码中的版本、依赖与运行条件写在正文；没有执行过的示例不标为“验证通过”。本次整理只补充标题、摘要、导读和示意图，没有把历史代码升级为已验证教程。

### 分享封面

- 所有公开文章构建独立的 1200 × 630 PNG：浅纸底 `#F7F5EF`、墨色 `#292824`、辅助灰 `#68645E`、朱砂 `#964D3B`、分隔线 `#DCD7CD`。
- 固定署名与域名位置；标题与摘要来自文章字段，字体使用仓库内的 Noto Serif CJK SC。字体仅在构建使用。
- 图片使用内容指纹命名，标题或摘要变化时产生新 URL，避免沿用旧图地址。变更字体或排版需提升模板版本；缓存位于 `.cache/paper-share/`，不提交。
- Open Graph / X 分享字段、页面标题与文章内容一致，图片采用配置的公开站点绝对地址。图片尺寸是本站设计选择，不保证所有平台以相同方式裁切。
- 分享图片固定浅色，跨设备保持一致，不跟随网页深色偏好。

### 摘录与解释性配图

- 摘录使用 1080 × 1440 竖版 PNG，用户通过原生选择框选择导读或正文段落。整段引用作为整体处理，保留内部署名；正文原文不改写。
- 图片包含文章标题、原文 URL 和 `quote_attribution`；引用内容必须可追溯。超过排版范围时提示换段，不默默截断。
- 解释性配图围绕流程、对照或概念关系；标明适用范围，不用装饰图代替解释。优先可维护的 SVG，保留文字替代与图注。
- 桌面横图 960 × 540，手机竖图 480 × 780；必须在实际宽度下检查文字。当前三张示意图分别解释阶段依赖、注释意图与命名信息。

### 组件与深浅色

- 搜索、导航、摘录弹窗复用 a11y-dialog；复制链接和代码使用原生 Clipboard API，不支持时复用 ClipboardJS；选择框、按钮、目录使用原生元素。
- 所有操作共用 `.ui-button`，44px 最小高度、3px 圆角、2px 焦点边框与 3px 偏移。新增状态使用语义颜色变量，不为单个模块另建风格。
- 深色：纸底 `#24231F`、内层 `#2F2D28`、正文 `#E9E4D9`、辅助文字 `#B3ADA1`、边线 `#4B473E`、强调 `#DFA08B`。
